## ✦ SEAM / Research System

<table>
<tr>
<td width="55%" valign="top">

### SEAM — Surface Encoded Agent Memory

SEAM is my work toward a memory substrate for AI systems that need more than a temporary context window.

The direction is **persistent, provenance-tracked, queryable memory** designed for agents that need to preserve useful experience across long-running work.

`memory` · `persistence` · `provenance` · `retrieval` · `agentic systems`

**Research principle:** preserve what matters, make it inspectable, and keep the path from memory → answer auditable.

</td>
<td width="45%" valign="top">

### Current Questions

```text
How should an agent remember?
        ↓
What deserves persistence?
        ↓
How do memories stay traceable?
        ↓
How do we query without losing meaning?
        ↓
How does memory change long-horizon agency?
```
